Problem

When CPA spikes, most teams raise or lower bids and hope. The real cause — audience exhaustion, floor price violations, creative fatigue — is buried in metrics no one has time to cross-reference. Bad diagnosis is worse than no diagnosis: it burns budget on the wrong fix.

Campaign Health pre-processes your metrics before the LLM call — computing week-on-week trends, detecting anomalies, and flagging benchmark deltas. Claude then receives calibrated signals, not raw numbers, and returns a diagnosis with root causes ordered by severity and a prioritised action list — not symptoms, causes.

Architecture

Pre-process first.
Then diagnose.

Rule-based preprocessing reduces token cost and improves diagnostic accuracy — the LLM sees signals, not noise.

Features

Root causes.
Not symptoms.

Every feature is designed to surface why a campaign is underperforming, not just that it is.

Pre-LLM Preprocessor
Derives metrics, detects anomalies, and computes benchmark deltas before the LLM call. Improves diagnostic accuracy and reduces token cost — the model reasons over signals, not raw CSV rows.
15+ Metric Support
CTR, CPA, CPC, CVR, win rate, ROAS, frequency, viewability, budget utilisation, floor price, and more. Handles both display and search campaign shapes.
Industry Benchmarks Built-in
0.1% display CTR, 2% search CTR, 15% win rate floor — built-in reference points mean diagnosis is calibrated against reality, not just internal campaign history.
Severity Ordering
Issues ordered by business impact — critical, warning, info — not by metric order in the CSV. Account managers know what to fix first without reading the whole report.
Batch Diagnosis
Diagnose an entire campaign fleet from a single CSV. Cross-campaign pattern summary highlights systemic issues — budget allocation problems, shared creative fatigue, floor-price violations at scale.
Root Cause Not Symptoms
Not "CTR is low" — but "bidding ₹15 below floor at ₹18 means you're not in the auction. This is not a creative problem." Diagnosis is precise enough to act on immediately.
Quickstart

Running in
three minutes.

Setup
git clone https://github.com/swapnanil/campaign-health
cd campaign-health
cp .env.example .env   # add your ANTHROPIC_API_KEY
docker-compose up api
CLI — diagnose a campaign CSV
docker-compose run cli diagnose \
  --file examples/sample_campaign_cpa_spike.csv \
  --format markdown
CLI — batch diagnose a fleet
docker-compose run cli batch \
  --file examples/campaign_fleet.csv \
  --format json --output reports/
